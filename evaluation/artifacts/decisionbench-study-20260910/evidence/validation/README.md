# 评测方法验证样本

固定24个构造输出：学习规划、主动介入、成果验收、计划调整各两组情境；每组包含正确结果、具体缺陷结果和严重错误结果。它们用于检验评测方法，未由产品模型生成。

题材为CSV清洗、二分查找、提醒冷却、跨午夜静默、列表去重、JSON异常处理、预算撤销及旧稿缺失。构造脚本为`evaluation/scripts/build_decisionbench_method_validation.py`。作者与逐例复核者均为本次主AI。

每组共享原始情境，通过修改明确内容或最终效果形成差异。质量标签及具体错误写在`private-labels.json`；评分请求只读取`evidence`，不接收标签和样本代号。良好、中等、严重三档是相对质量分组，中等组可以因教学方法不可用而不通过。

本集在方法开发后固定，随后每个输出独立评分3次，统计严格三档排序、正确结果优于严重错误、结论一致率、逐维一致率和分数标准差。新题材与数字用于检查方法迁移；错误类型与开发目标有关，不将其表述为完全未见缺陷或独立人类标注。

相同严重错误的8个措辞攻击变体位于`../adversarial`，保留行为和状态，附加术语与操纵评分的指令。将它们与原严重错误配对，检查是否因篇幅和自我宣称而误获通过。
