# 双人人工盲标确认与自动评分对齐

作者于2026年9月10日确认：两位标注者各自独立盲标全部128个评分位置，七个维度及通过结论逐项一致，且与已归档复核结论一致。人工之间逐项一致率为100%。本确认覆盖首轮48次应用、72次方法验证和8次评分操纵对抗；新增方法实验不在这次人工覆盖范围内。

## 可复算的自动—人工对齐

48个应用案例有完整的七维复核数值，作者确认人工与这些数值相同，因此可将原自动评分与其直接比较：通过结论46/48一致；逐维一致率和二次加权Kappa见`application-alignment.csv`。Kappa按等级差的平方计不一致，分母为双方边际分布下的期望不一致；当所有样本都在同一档位时，Kappa无定义，记录为空，直接一致率仍可报告。

另外80个位置的既有复核记录保存逐维已检查及定性发现，没有逐项修订后的数值向量，因此不从“已检查”推造新的数值标签，不计算这80个位置的数值Kappa。
