# DecisionBench：学习决策评测集

本集服务于 Learning Agent 的四类开放式决策：如何规划学习、何时提供帮助、如何验收成果、如何调整计划。输入包含用户要求、已有学习状态与可用材料；合理输出可以有多种，评价依据是约束、证据与实际效果。

## 应用样本

[application](application/manifest.json)含48个输入，四类各12个。全部由项目作者构造合成学习情境，不含真实学习者信息；难度分层为标准16、困难24、对抗8。技术主题包括校验和、模幂、杨辉三角、舍入、全加器、约瑟夫环、复数乘法、硬币组合、Softmax、卷积、Base64和饱和加法。

这些输入复用先前的48例固定集合，以便检查同一批用户条件下的完整行为。旧样本中的测试标签描述其初次冻结时的角色；本轮已阅读历史输出并据此修订评测方法，因此不将本轮结果称为未见场景泛化实验。真实模型输出、失败记录和评分随实验档案发布，不放进应用输入。

每例独立使用临时数据库、冻结时间和资源快照。通知写入隔离收件箱。模型调用使用真实配置的Hy3接口，保持唯一费用账本。

## 方法验证

方法验证使用单独构造的输出，显式给定质量差异和观察到的状态。质量标签保存在评分输入之外，用于计算排序是否正确。[方法验证](method-validation/README.md)包含24份输出，每份评价3次；[评分操纵对抗](adversarial/README.md)包含8份输出，每份评价1次。实验已完成，见[完整结果](../../artifacts/decisionbench-study-20260910/README.md)。

## 新场景方法扩展

[严重失败识别验证](extensions/severe-validation-20260910/README.md)在第9版方法冻结后新增12个场景族、24份正常/严重输出，各评3次。它独立于主体72份及8份评分操纵对抗，检验严重漏检与正常误报。

## 目录与来源

- `method-validation`：24份三档输出、公开证据及独立标签。
- `adversarial`：8份行为不变的评分操纵变体。
- `application/cases`：48个可执行情境。
- `application/resources`：固定教学材料。
- `application/manifest.json`：输入清单。
- `application/benchmark-release.json`：输入和工程协议的来源绑定。
- 旧输入来源：`../decisionbench-v1.13-e6-final-test`；原始字节保留，当前绑定明确使用恢复产品提示后的代码。

数据、构造脚本与项目采用同一仓库许可证。当前集与旧目录的关系见[上层索引](../README.md)。
