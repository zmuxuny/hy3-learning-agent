# DecisionBench：学习决策评测集

本集服务于 Learning Agent 的四类开放式决策：如何规划学习、何时提供帮助、如何验收成果、如何调整计划。输入包含用户要求、已有学习状态与可用材料；合理输出可以有多种，评价依据是约束、证据与实际效果。

## 应用样本

[application](application/manifest.json)含48个输入，四类各12个。全部由项目作者构造合成学习情境，不含真实学习者信息；难度分层为标准16、困难24、对抗8。技术主题包括校验和、模幂、杨辉三角、舍入、全加器、约瑟夫环、复数乘法、硬币组合、Softmax、卷积、Base64和饱和加法。

应用输入是48个已固定的情境，其真实模型输出、失败记录和评分随实验档案保存。应用实验描述这些给定条件下的决策表现。另有方法冻结后构造的正常/严重对照，记录不同材料上的识别结果。

每例独立使用临时数据库、冻结时间和资源快照。通知写入隔离收件箱。模型调用使用真实配置的Hy3接口，保持唯一费用账本。

## 方法验证

方法验证使用单独构造的输出，显式给定质量差异和观察到的状态。质量标签保存在评分输入之外，用于计算排序是否正确。[方法验证](method-validation/README.md)包含24份输出，每份评价3次；[评分操纵对抗](adversarial/README.md)包含8份输出，每份评价1次。实验已完成，见[完整结果](../../artifacts/decisionbench-final-method-20260910/README.md)。

## 正常与严重错误对照

[严重失败识别验证](extensions/severe-validation-20260910/README.md)包含12个场景、24份正常/严重输出，各评3次，共72次评分。具体材料在方法冻结后构造，用于同时检验严重错误识别与正常误报。全部104份输入的评分使用同一最终方法。

## 目录与来源

- `method-validation`：24份三档输出、公开证据及独立标签。
- `adversarial`：8份行为不变的评分操纵变体。
- `application/cases`：48个可执行情境。
- `application/resources`：固定教学材料。
- `application/manifest.json`：输入清单。
- `application/benchmark-release.json`：输入和工程协议的来源绑定。
- `extensions/severe-validation-20260910`：24份正常/严重输出及独立标签。
- 输入来源：`../decisionbench-v1.13-e6-final-test`；原始字节保留，应用运行的源码版本与输入绑定单独保存。

数据、构造脚本与项目采用同一仓库许可证。当前集与旧目录的关系见[上层索引](../README.md)。

## 条件适用范围验证

[条件核验对照](extensions/condition-validation-20260910/README.md)包含6组成对材料、12份输出，各评3次，检验平方与开方、升序拼接、整除、准确率合并、任务单段长度及负荷变化。与主体104份输入合计116份；主体200个评分位置与条件专项36个位置分别汇总，方法相同。
