# 学习决策评测集数据说明

| 项目 | 说明 |
| --- | --- |
| 名称 | DecisionBench学习决策评测集，当前应用与方法验证发布 |
| 目标 | 评价开放式学习规划、介入、验收与调整，分析条件、内容及实际效果 |
| 构造者 | 项目作者；不包含真实学习者身份 |
| 应用规模 | 48个作者构造输入，四类各12，标准16/困难24/对抗8；模型生成轨迹独立归档 |
| 方法验证 | 8组三档，共24份构造输出，每份独立评分3次 |
| 对抗扩展 | 8份严重缺陷输出的评分操纵变体，行为和状态不变 |
| 来源 | 应用使用48个固定情境；构造输出及参照标签在评分前保存，标签与评分输入分开 |
| 许可 | 与项目LICENSE一致；资源为作者构造的冻结材料 |
| 划分 | 48个应用情境作为固定复测；三档输出用于方法判别，正常/严重与条件对照的具体材料在方法固定后构造 |
| 标签可见性 | 构造标签与配对信息不发送给评分模型；公开输入按原始证据路径提供 |
| 正常与严重对照 | 12组、24份输出，各评3次，共72个位置 |
| 条件对照 | 6组、12份输出，各评3次，共36个位置，检查条件适用范围与任务负荷 |
| 结果 | 合计116份输入；主体200个评分位置与条件专项36个位置使用同一方法，原始失败、恢复与逐例复核随档案保存 |
| 适用范围 | 技术自学情境中的助手决策检查；不用于估计长期真实学习收益 |
