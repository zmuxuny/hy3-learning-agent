# 条件适用范围与任务负荷：成对验证

本组含6个具体场景，每个场景有条件正确、条件遗漏或负荷矛盾的两份输出，共12份。全部由作者构造，在评分前固定；使用与主体实验相同的最终方法，每份独立评分3次，共36个位置。

| 场景 | 条件正确的输出 | 缺陷输出及可核对的反例 |
| --- | --- | --- |
| 平方后开方 | 实数x满足sqrt(x*x)=abs(x)，非负时才等于x | 声称对正负实数都等于x；x=-3时结果为3 |
| 有序列表拼接 | 非空升序列表A、B还需A末项不大于B首项 | 只凭各自升序就断言拼接升序；[1,4]+[2,3]不满足 |
| 整数除法分配 | 双方为偶数时可分配，并列出不能推广的反例 | 任意非负整数都可分配；(1+1)//2=1，而1//2+1//2=0 |
| 合并正确率 | 按题数加权；两组题数相同可取简单平均 | 任意组大小均取简单平均；1/1与0/9合并为10%，不是50% |
| 单段任务长度 | 40分钟拆成4×10，满足单段不超过10分钟 | 拆成10+30，虽然总量40正确，最长段30仍超限 |
| 保留与新增负荷 | 将一项20替换成10+10，另一项20保留，总量40 | 保留原40再增加20，却称仍为40；周预算100不代表没有新增负荷 |

完整原句见[独立用例目录](../../../../../评测用例目录.md)。[suite.json](suite.json)列出12个输入及证据摘要；`evidence/`包含请求、状态及构造回复；[private-labels.json](private-labels.json)是评分外的参照标签；[design.json](design.json)固定方法来源、输入摘要、3次重复和仅无分恢复规则。输入是受控的短材料，卷积真实长计划的核验难点另在报告第6.2节分析。

结果见[条件验证档案](../../../../artifacts/condition-validation-20260910/README.md)。方法评分的通过与否、是否明确认出条件缺陷分别复核，所有无分均保留。
