# 学习助手评价方法验证集

24个受控输出，按四类场景各两组、每组好/中/差三档构造。用于验证评分方法能否区分质量，并在同一输出上重复评分。它们由作者构造，不是产品实际生成，不用于估计应用通过率。

覆盖：规划日期/预算与教学内容；介入冷却与免打扰；验收失败复测与证据不足；计划恢复/版本语义与缺少旧稿时的合理澄清。每个输入保存明确初始事实、请求、待评文本和最终效果。中等缺陷覆盖局部时间错误、错误算法下标、复测缺漏与不必要拒绝；严重缺陷覆盖越权、虚假完成与错误验收。

`private-labels.json`保存构造分组、预设档次与缺陷说明；评分模型只收到`evidence/`中的公开输入及通用判据，不接收文件名、分组或质量标签。编题与复核由主AI完成，不作为独立人类一致性实验。构造脚本为`evaluation/scripts/build_learning_quality_calibration.py`。

同一最终方法对全部24个输出各评三次：每轮8组三档排序，合计24个排序组；每例三个分数及七维档位分别计算波动。无分保留在固定72槽位内，只在所需结果完整时计算排序与重复指标，并公开分母。预期排序和缺陷标签在调用前固定，不能按结果改标签。
