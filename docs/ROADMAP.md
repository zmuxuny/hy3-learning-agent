# 开发路线图

## 项目管理规则

- `STATUS.md` 是当前进度事实来源。
- 每个里程碑都有可运行验收流程，不以文件数量判断完成。
- 参赛 MVP 优先保证两条真实 Hy3 端到端流程。
- 演示数据必须标明真实调用或固定夹具，不能混淆。
- 新 Git 仓库只在清理后的版本完成验证后初始化。

- [x] 冻结产品方向和 Harness 架构
