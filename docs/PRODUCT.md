# 产品功能与使用边界

Learning Agent · Hy3面向编程与技术自学者，将目标澄清、学习计划、成果反馈和过程支持放在同一工作台。用户可以从不完整的目标开始，逐步形成可审阅、可执行和可调整的学习安排。

## 功能与用户流程

| 环节 | 用户操作 | 应用行为 |
| --- | --- | --- |
| 目标建立 | 描述已有基础、期望作品和可用时间 | 记录已知条件，询问影响计划的缺项 |
| 路径规划 | 审阅任务、资源、期限和验收要求 | Hy3生成提案，用户采用后进入计划工作区 |
| 学习执行 | 查看任务，提问，提交代码、文件或结果 | 结合任务要求解释内容并检查学习证据 |
| 成果反馈 | 阅读通过、退回或补充材料的意见 | 保存依据和下一步，支持针对失败条件复测 |
| 主动支持 | 设置提醒偏好并查看收件箱 | 根据学习状态选择等待、提醒、教学、抽查或调整建议 |
| 计划调整 | 提供新的时间条件或批准修改 | 在授权范围内调整，保留无关任务和已有证据 |

## 用户控制

新计划以提案方式审阅；材料中的文字不构成用户批准。提醒需要考虑免打扰、频率和冷却，保持安静也可以是正确决策。学习状态、长期记忆与操作来源可追溯，用户能够确认、纠正或恢复相关信息。

## 运行方式

项目面向个人电脑或个人服务器上的单用户使用。默认本地模式监听回环地址；服务器模式需要配置认证与允许的来源。应用使用Vue、FastAPI和SQLite，通过环境配置调用Hy3。安装与启动见[README](../README.md)，部署见[安全说明](../SECURITY.md)。
