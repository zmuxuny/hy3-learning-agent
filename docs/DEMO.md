# 完整 Demo 录制脚本

## 录制前

启动 `./scripts/start.sh`，打开 `http://127.0.0.1:8000`。在 `.env` 配好 Hy3；邮箱是可选项，未配置时只展示站内收件箱。

## 一条连续主线

1. 新对话输入：

   > 我想在 7 天内掌握 FastAPI Agent Harness。先搜索并打开可靠的官方学习资源，然后根据我每天 90 分钟、需要完成一个可运行项目的条件创建完整计划。核心任务必须要求代码或文件证据，并把学习时间写入日历。

2. 展开运行轨迹，展示 `web_search → web_open → plan_create → calendar_create`。进入计划工作区，展示唯一计划标题、进度摘要和纵向时间线。

3. 在计划页输入：

   > 我今天只有 45 分钟。读取当前计划并调整今天的任务，但不要改变最终目标；所有修改必须可撤销。

4. 点击某个核心任务的“提交成果”，把文件放入 `data/workspace/demo/` 后告诉 Agent 路径。要求它使用 `file_read`，需要时调用 `code_execute`，再执行 `submission_create` 和 `submission_check`。

5. 展示任务完成、进度和 XP 更新；让 Agent 创建一次测验并用 `review_schedule` 安排复习。

6. 点击侧栏“学习 Agent 在线”触发一次立即检查。展示 Agent 读取到期任务/复习、决定提醒，并在“收件箱”出现站内消息。邮箱配置存在时同时展示邮件。

7. 打开运行抽屉，撤销一次计划或日历调整，证明写操作可审计、可恢复。

## 建议镜头

- 对话页没有重复 Header；工具步骤内联，答案按 Markdown 排版。
- 计划详情只保留计划名作为页面标题。
- 运行抽屉展示工具参数/结果，不展示私有思维链。
- 录制一次 2560×1440 桌面效果，再补一个 375px 移动端镜头。
