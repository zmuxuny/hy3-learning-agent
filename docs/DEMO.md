# 完整 Demo 录制脚本

## 录制前

启动 `./scripts/start.sh`，打开 `http://127.0.0.1:8000`。在 `.env` 配好 Hy3；邮箱是可选项，未配置时只展示站内收件箱。

## 一条连续主线

1. 在计划首页点击“用 Agent 创建”，只给一个不完整目标：

   > 我想学会 FastAPI，并做一个真的能运行的 Agent 项目。

2. 展示 Agent 把已知事实和 1–3 个关键问题保存为提问卡。选择“7 天 / 每天 90 分钟”，补充“交付可运行 Harness，核心任务要代码证据”，提交后卡片原位结束而不是再发送一条普通气泡；展开最新消息下的工作记录，展示课程设计、资源调研或考核审查子 Run 的分工与返回。
3. 展示计划提案的阶段、任务、预计时间与主 Agent 理由。点击“采用并创建计划”，说明采用前数据库没有正式 Plan；再点击“在计划中继续”，进入带交接摘要的计划 Session。
4. 在计划对话点击“教我下一步”，展示 `study_state_get` 选择当前任务，然后只给一个概念和小练习。侧栏仍只有连续 Session，首轮生成语义标题可手动改名。

5. 悬停刚才“教我下一步”的用户消息，点击编辑，补充“先用类比讲解，再给练习”并重新运行；说明旧版本、旧 Run 和操作仍留在审计中，旧回复不再进入当前上下文。

   > 教我下一步。请先判断我现在进行到哪一个任务，只讲当前需要的概念并给我一个小练习。

6. 在计划页输入：

   > 我今天只有 45 分钟。读取当前计划并调整今天的任务，但不要改变最终目标；所有修改必须可撤销。

7. 点击某个核心任务的“提交成果”，把文件放入 `data/workspace/demo/` 后告诉 Agent 路径。要求它使用 `file_read`，需要时调用 `code_execute`，再执行 `submission_create` 和 `submission_check`。

8. 展示任务完成、进度和 XP 更新；让 Agent 创建一次测验并用 `review_schedule` 安排复习。

9. 先在“收件箱”展示全局心跳的上次判断、下次时间与 24 小时进度询问条件；点击侧栏“学习 Agent 在线”触发一次立即检查。展示 Agent 读取到期任务/复习、决定提醒，并在“收件箱”出现无需邮箱的站内消息；随后归档消息、进入“已归档”并恢复，证明通知可整理且不丢失。邮箱配置存在时再展示可选邮件。

10. 打开运行抽屉，撤销一次计划或日历调整，证明写操作可审计、可恢复。归档并恢复一条对话和一份计划，展示数据仍然存在。

## 建议镜头

- 对话页没有重复 Header；最新 Run 工作记录默认折叠、可展开，答案由完整 CommonMark 解析器处理标题、列表、引用、表格、链接和代码块。
- 计划详情只保留计划名作为页面标题。
- 运行抽屉展示工具参数/结果，不展示私有思维链。
- 提问卡、提案和消息编辑在 375px 下改为单列，不出现横向滚动。
- 录制一次 2560×1440 桌面效果，再补一个 375px 移动端镜头。
