# 学习助手与评测 Demo

[观看108秒视频](learning-agent-stage3.mp4) · [封面](cover.png) · [剪辑时间线](learning-agent-stage3.json)

1920×1080、25fps。应用素材来自2026-09-10真实Hy3调用：提出目录统计工具目标，确认学习条件，展开提案验收要求，采用计划并进入计划工作区。评测素材展示首轮实验的原始输出、开发复核、三档判别及四类结果；结尾同步新增方法的严重36/36识别、正常36/36通过，以及首轮128个位置的双人人工确认。

所有浏览器素材以1440×900完整视口录制，按比例缩放到1600×1000，置于1920×1080画布；说明字幕放在新增顶部80像素区域，未裁剪网页顶边、侧栏或底部。视频剪去了模型与网络等待，应用条件确认和工具重试保存在原始调用证据中。

## 时间安排

| 时间 | 内容 |
| --- | --- |
| 0—8秒 | 目标用户、应用与评测任务 |
| 8—16秒 | 真实输入：作品目标、时间与资源 |
| 16—42秒 | 提案、验收细则、采用与计划工作区 |
| 42—52秒 | 评价材料与七维方法 |
| 52—92秒 | 具名案例、原始内容、复核证据及有效性图表 |
| 92—108秒 | 人工确认、新方法严重识别与正常通过、交付入口 |

`sources`保存原始录屏和动作时间标记。`recorded-evidence.tar.gz`保存真实对话、提案、计划、工具调用、状态、录制脚本与本轮前期录制调用记录。素材源码217c880；前端随后补充成功提案事件的标题列表刷新，不改变模型内容。全部Hy3调用沿用唯一费用账本。

